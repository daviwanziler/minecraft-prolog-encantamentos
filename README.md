# minecraft-prolog-encantamentos
# Sistema Inteligente de Encantamentos do Minecraft (Jogo)

## 1. Introdução

Este projeto tem como objetivo desenvolver um sistema inteligente utilizando a linguagem PROLOG, baseado nos encantamentos presentes no jogo Minecraft.
O sistema utilizará uma base de conhecimentos composta por fatos e regras para consultar informações, verificar compatibilidades e realizar inferências sobre livros encantados e equipamentos.

## 2. Objetivo Geral

Desenvolver uma aplicação em PROLOG capaz de representar e consultar conhecimentos sobre os encantamentos do Minecraft, utilizando conceitos de programação lógica.

## 3. Objetivos Específicos

- Cadastrar os principais encantamentos do jogo.
- Identificar os equipamentos compatíveis com cada encantamento.
- Consultar os níveis máximos dos encantamentos.
- Identificar encantamentos incompatíveis.
- Criar regras para realizar inferências a partir dos fatos cadastrados.

## 4. Tecnologias Utilizadas

- PROLOG
- SWI-Prolog
- GitHub

## 5. Funcionalidades Previstas

- Consulta de encantamentos.
- Verificação de compatibilidade.
- Consulta de níveis máximos.
- Identificação de incompatibilidades.
- Recomendações de encantamentos para equipamentos.

## 6. Desenvolvimento

O projeto será desenvolvido por meio de uma base de fatos e um conjunto de regras lógicas, permitindo que o sistema responda a consultas e realize inferências.
